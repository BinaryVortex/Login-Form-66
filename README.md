# Login Form

A clean, minimal responsive login form built with HTML and CSS.

![Login Form screenshot](./Screenshot%202024-07-29%20091911.png)

## Features

- Simple, modern UI
- Responsive layout for desktop and mobile
- HTML + CSS only (no JavaScript required)
- Easy to customize colors, fonts and layout

## Demo / Usage

To open the project locally:

- Option 1: Open `index.html` directly in your browser (double-click the file).
- Option 2: Serve the folder with a simple local server (recommended for some browsers):

  ```bash
  # Python 3
  python3 -m http.server 8000
  # then open http://localhost:8000
  ```
